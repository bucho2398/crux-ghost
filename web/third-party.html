Local by design.

The video engine runs in a Web Worker on your own device. Video files are never uploaded. The website only downloads application files, the engine and optional demo clips. It includes no analytics.

Quality & compatibility

Version 0.1 supports browser-playable, 8-bit SDR video. HDR, Dolby Vision, 10-bit, anamorphic pixels and mismatched color spaces are rejected before rendering. The export canvas uses the maximum width and maximum height of the two oriented sources, with up to one pixel of even padding. Smaller clips are centered at native size. Frame rate is the higher source rate, including rational rates such as 60000/1001. Variable-frame-rate footage is resampled to that average rate.

High quality uses H.264 CRF 10; this is a re-encode, not an identical copy. RGB lossless uses H.264 RGB CRF 0, avoiding additional codec loss after the blend and color conversion. RGB lossless and higher chroma formats may need VLC or another capable player. Selected audio is synchronized and encoded as AAC at 320 kb/s. Position and scale adjustments intentionally alter placement; scaling may resample and shifting may crop.

The browser engine has a 2 GB input-file limit and also needs memory for frames and output. A phone can reach its memory limit much earlier. Use shorter clips without lowering their resolution, or a more capable device. Keep the app foregrounded; iOS can suspend background pages. Processing can take longer than the clip’s running time.

FFmpeg / ffmpeg.wasm

This app distributes the unmodified single-thread @ffmpeg/core 0.12.10, including FFmpeg and its linked codecs. The core is GPL-licensed. Source, build configuration and dependency sources are available in the upstream project and source repository. See the included GPL v2, GPL v3, LGPL v2.1 and LGPL v3 texts. Exact upstream source revision and archive are recorded in the source manifest.

The private authoring repository contains the comparison logic and build tools. Its compiled worker is necessarily downloaded by visitors and can be inspected. Keeping source private does not make client-side code secret. The compiled comparison worker is distributed under the same terms as its public wrapper (MIT), separately communicating with the GPL core through its command interface. Demo videos and app artwork were generated for this project.

Android

The Android shell uses AndroidX WebKit (Apache 2.0) for secure local asset loading. It requests Internet access for external links and uses the system file picker for videos. It saves exports through Android’s MediaStore; no broad storage or camera permission is needed.
